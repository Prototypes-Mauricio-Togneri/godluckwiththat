  Description & Suggested Fix: Dual CSS declarations without fallback comment.
    Properties like gap: 0.45rem; gap: 7cqh; appear throughout — the rem value
    serves as a fallback for browsers not supporting container query units. This

    is a valid progressive enhancement pattern but is nowhere documented. Fix:
    Add a one-line comment at the first occurrence (e.g. /* rem fallback for 
    browsers without cqh support */).
