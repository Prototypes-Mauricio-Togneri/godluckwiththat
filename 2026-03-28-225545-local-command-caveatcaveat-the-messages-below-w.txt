  Issue Type: Vue Anti-pattern
  Line #: 54
  Severity: Style
  Description & Suggested Fix: Array index used as v-key. <p v-for="(para, i) in
   
    paragraphs" :key="i"> uses index keys on a computed list derived from
    props.body.split('\n'). When the same modal instance receives different body

    text, Vue may reuse DOM nodes incorrectly. In practice risk is low because
    help_modal is typically destroyed/recreated via v-if. Fix: Use :key="para"
    (paragraph text is unique per body) or :key="'p-' + i" with a comment
    explaining why index is acceptable here.

  Description & Suggested Fix: Dual CSS declarations without fallback comment.
