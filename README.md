# Tension Node

Show life bar (space bar to show/hide)
Repair with middle click
Show building stats when clicked
Paint coordinates
Blur background when showing main menu
Show direction in connections
Add energy nodes
Add more mines and connect them all
Add connection model

## Resources
* Metal
* Crystal
* Deuterium

## Defenses
* Wall
* Light turret
* Heavy turret
* Ion turret
* Gauss turret
* Plasma turret
* Pulse turret

- Shotgunner
- Ranger
- Sprayer

## Upgrades
* Increase building hp
* Increase building shield
* Buildings consume less energy
* Connections move more resources per second
* Mines collect more resources per second

## Features
* Campaign mode
    - Maps are fixed
    - Map 1 has only one big wave
    - Map 2 has one wave, then expands and has a second wave
    - etc
* Infinite mode
    - Maps are generated randomly
    - After each big wave, the map expands
* Map editor
