# God Luck With That

[Web site](https://god-luck-with-that.web.app)

- Resources
  - Show: "Full in [TIME]" or "Empty in [TIME]"
  - Show progress bar in each resource to indicate how full it is

- Events
  - Left bar (past events)
    - season_change_coming
    - disaster_result
    - challenge_result
    - building_upgraded
    - research_completed
    - population_limit_reached
    - resource_limit_reached
    - territory_limit_reached
  - Right bar (future events)
    - attack
    - challenge
    - research
    - building_upgrade
    - next_quest
