Description & Suggested Fix: Bulk trade double-floor rounding gives a slight 
  discount. buyPrice() returns floor(base × (1 + fee)), then executeTrade
  applies floor(... × multiplier). For a 1000-unit buy at base price 33 with
  30% fee: floor(floor(33 × 1.3) × 10) = floor(42 × 10) = 420, vs the
"correct"
    floor(33 × 1.3 × 10) = floor(429) = 429. Bulk buyers save gold. The display

  (scaledBuyPrice in market_modal.vue:60) uses the same formula, so UI matches

  execution — but the economic advantage is unintentional. Apply fee to the 
  scaled amount:  floor(base × multiplier × (1 + fee)).
